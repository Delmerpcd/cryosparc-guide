CryoSPARC 单颗粒分析工作流程

基于 CryoSPARC 官方指南整理的中文学习资料，涵盖从原始数据导入到最终三维结构验证的完整单颗粒冷冻电镜（Single Particle Cryo-EM）数据处理流程。

工作流程总览

CryoSPARC 单颗粒分析包含 6 个主要阶段、20+ 个作业类型。从原始电影文件（Movies）出发，经过漂移校正、CTF 估计、颗粒挑选、二维分类、三维初模重建、精修优化，最终获得高分辨率三维密度图。

第一阶段：预处理

预处理是数据质量的基石——在此阶段剔除不良照片，可避免下游分析中 "垃圾进、垃圾出" 的问题。

1.1 导入原始数据 Import Movies

作业类型

Import Movies

将原始电影文件（TIFF、MRC、EER 等格式）导入 CryoSPARC 项目。需提供增益参考文件（Gain Reference）和坏点文件（Defect File）。

参数说明典型值
Pixel Size (Å)像素尺寸1.0–1.5
Accelerating Voltage (kV)加速电压200 / 300
Spherical Aberration (mm)球差系数2.0 / 2.7
Total Exposure Dose (e⁻/Å²)总电子剂量40–60
提示：EER 格式数据需额外设置分帧数（Number of Fractions）和上采样因子（Upsampling Factor）。导入 EPU XML 元数据可自动解析束位移值。

1.2 漂移校正 Patch Motion Correction

作业类型

Patch Motion Correction (Multi)

对每张电影进行全帧、分块（Patch-based）局部运动校正。相比传统的整帧刚性校正，分块校正能更好地建模局部的各向异性束诱导运动。输出剂量加权的对齐显微照片。

参数说明建议值
Maximum alignment resolution (Å)对齐分辨率上限3–5
Number of GPUsGPU 数量（Multi 版本）2–4

1.3 CTF 估计 Patch CTF Estimation

作业类型

Patch CTF Estimation (Multi)

使用分块方法估计每张显微照片的衬度传递函数（CTF）参数。对于倾斜或非均匀样品，分块方法比整张照片的 CTFFIND4 更准确。

参数说明建议值
Min / Max defocus (Å)离焦搜索范围5000–50000
Minimum CTF fit resolution (Å)CTF 拟合最低分辨率5–6
提示：CTF 拟合分辨率差于 5–6 Å 的显微照片通常需要在下一步筛选中剔除。

1.4 照片筛选 Manually Curate Exposures

交互式

Manually Curate Exposures

打开交互界面，检查每张显微照片的 CTF 拟合质量、像散（Astigmatism）、估计冰层厚度、运动路径和功率谱。通过滑块设定阈值剔除不良照片。

筛选指标建议阈值说明
CTF Fit Resolution< 5–6 Å剔除 CTF 拟合差的数据
Astigmatism< 400 Å剔除像散过大的照片
Ice Thickness视情况剔除冰层过厚或过薄的区域

第二阶段：颗粒挑选与提取

颗粒挑选是决定最终分辨率的关键环节。推荐采用两阶段策略：先用快速方法粗选，生成模板后再用模板挑选获取高质量颗粒。

2.1 Blob 自动挑选 Blob Picker

GPU 作业

Blob Picker

基于高斯拉普拉斯算子（Laplacian-of-Gaussian）的快速无模板颗粒检测器。适合初步粗选，产生初始颗粒集用于后续模板生成。

交互式

Inspect Particle Picks

通过 NCC（归一化互相关）分数和局部功率（Local Power）两个滑块交互式筛选颗粒，剔除碳膜边缘、晶冰等污染物。

参数说明建议值
Min / Max particle diameter (Å)颗粒直径范围100–300
Min separation distance颗粒间最小间距0.5–1× 直径

2.2 Template 模板挑选 Template Picker

GPU 作业

Template Picker

使用优质 2D 类别图像作为模板，通过互相关搜索进行颗粒挑选。相比 Blob Picker，假阳性率大幅降低，颗粒定位更准确。

最佳实践：先手动挑选 ~200–1000 个颗粒 → 2D 分类得到模板 → 再用 Template Picker 在全数据集上挑选。这是目前最常用的高精度挑选策略。

2.3 Topaz 深度学习挑选

深度学习

Topaz Train / Extract

基于深度学习的颗粒挑选方法。需要约 1,000 个手动挑选的颗粒用于训练模型。训练完成后可对整个数据集进行高质量自动挑选，效果常优于 Template Picker。

提示：Topaz 需要手动挑选的颗粒覆盖不同离焦范围，确保模型泛化能力。

2.4 颗粒提取 Extract From Micrographs

作业类型

Extract From Micrographs

从显微照片中提取颗粒图像。初期使用 Fourier 裁剪（Binning 4–6×）大幅降低计算量；最终精修阶段再以全分辨率重新提取。

阶段Box SizeFourier Crop像素尺寸
初期分类256 px128 px (2× bin)~2.5 Å/px
最终精修256–320 px256 px (无裁剪)原始 ~1.2 Å/px
关键原则：早期阶段始终使用 Fourier 裁剪（4–6× binning）加速二维分类和初始模型重建；仅在最终精修时使用全分辨率。这可以节省大量计算时间。

第三阶段：二维分类

3.1 2D 分类 2D Classification (NEW)

GPU 作业

2D Classification

将提取的颗粒进行二维对齐和聚类，生成多个类别平均图。这是数据清理的核心步骤——通过视觉检查类别平均图来区分好颗粒与污染物/聚集物。

参数说明建议值
Number of 2D classes类别数量50–100（大数据集）
10–20（模板生成）
Batchsize per class每类批次大小200–400
Number of iterations迭代次数20–40（默认即可）
Remove duplicate particles去除重复颗粒true（球状蛋白）
false（螺旋/纤维状）

3.2 选取 2D 类别 Select 2D Classes

交互式

Select 2D Classes

交互式查看所有 2D 类别平均图，选取显示清晰二级结构特征的类别，剔除噪声、模糊、部分颗粒和冰污染类别。

选取标准剔除标准
清晰的二级结构细节噪声、模糊、低分辨率
锐利的边缘特征残缺/聚集颗粒
高颗粒数量冰污染、边缘伪影
多样的取向分布单一取向过度富集
重要：通常需要进行 2–4 轮 二维分类 + 选取，逐步清理颗粒堆栈。预期会丢弃初始挑选颗粒的 50–80%。不要期望一次性获得完美结果。

第四阶段：三维初始模型重建

4.1 Ab-Initio 重建 Ab-Initio Reconstruction

GPU 作业

Ab-Initio Reconstruction

使用随机梯度下降（SGD）算法从二维颗粒图像从头重建三维密度图，无需任何初始参考结构。运行 1–4 个类别可以在初始阶段就区分不同的构象/组成状态。

参数说明建议值
Number of classes初始模型类别数1–4
Symmetry对称性C1（不确定时）
Initial low-pass filter (Å)初始低通滤波30
Class similarity类别相似度默认
提示：建议运行多次 Ab-Initio，每次使用不同的类别数（如 2、3、4 类），在 ChimeraX 中检查哪个结果显示出可解释的结构特征。不确定对称性时使用 C1。

第五阶段：精修与优化

5.1 均质精修 Homogeneous Refinement (NEW)

GPU 作业

Homogeneous Refinement

将所有颗粒归入单一三维类别的迭代最大似然精修。适用于颗粒构象均一的样品。输出精修后的三维密度图、两个半图（用于 FSC）、Mask 和每颗粒对齐参数。

5.2 非均质精修 Heterogeneous Refinement

GPU 作业

Heterogeneous Refinement

使用多个初始三维模型（来自 Ab-Initio 的不同类别），让颗粒"竞争"分配到最匹配的体积。用于分离不同的构象状态或组成成分。选取最佳类别后，输入均质或非均匀精修。

5.3 非均匀精修 Non-Uniform Refinement

强力推荐 ⭐

Non-Uniform Refinement

均质精修的升级版，在空间频率上施加自适应正则化。几乎所有情况下都是最终高分辨率精修的首选，能显著改善高分辨率区域密度图质量。

参数建议值
SymmetryC1 / C2 / D2 / C4 等（按样品对称性）
Initial lowpass resolution12–15 Å
Dynamic maskingOn
Optimize per-particle defocusOn
Optimize per-group CTF paramsOn

5.4 局部精修 Local Refinement

高级

Local Refinement

当复合体存在柔性结构域时，创建软 Mask 覆盖该区域进行局部精修。允许柔性结构域相对于复合体其余部分作刚体运动，显著改善柔性区域密度图质量。

参数建议值
Fulcrum coordinatesMask 中心或铰链点坐标
Rotation search extent10–15°（取决于柔性程度）
Shift search extent3–5 Å
Use pose/shift Gaussian priorTrue

5.5 CTF 精修 Global / Local CTF Refinement

精修优化

Global CTF Refinement

按颗粒组精修高阶 CTF 参数（束倾斜、三叶像差等）。

精修优化

Local CTF Refinement

对每个颗粒单独精修 CTF 参数，进一步提高分辨率。

分辨率提升：全局和局部 CTF 精修通常可带来 0.1–0.3 Å 的分辨率提升。推荐的精修循环：Non-Uniform Refinement → Global CTF Refine → Non-Uniform → Local CTF Refine → Non-Uniform。

第六阶段：后处理与验证

6.1 锐化与局部分辨率

作业类型

Local Resolution Estimation

计算密度图每个体素的局部分辨率，用颜色编码显示在密度图表面。帮助识别柔性/无序区域。

作业类型

Sharpen 3D Map

应用 B 因子锐化密度图，补偿重建过程中的振幅衰减。可选择全局 B 因子或基于局部分辨率的锐化。

作业类型

Local Filtering

根据局部分辨率对锐化图进行局部滤波，优化不同区域的显示效果。

6.2 3D 变异性分析 3D Variability Analysis (3DVA)

高级分析

3D Variability Analysis

分析颗粒的连续构象异质性。通过主成分分析（PCA）识别主要的运动/构象变化模式，生成沿每个成分的密度图动画。适用于研究分子机器的动态过程。

高级分析

3D Flex

对连续柔性运动进行建模，在重建过程中补偿颗粒间的柔性差异，进一步提升重建质量。

附录 B：技巧与常见问题

为什么我的 2D 分类结果不好？

可能原因：颗粒挑选不准确（假阳性太多）、颗粒未居中、数据集异质性过高、Fourier 裁剪太激进。解决：优化挑选参数，尝试 Template Picker 或 Topaz。

Ab-Initio 重建看起来很怪？

尝试运行多个类别数（2/3/4类），其中"垃圾"类别会吸收不良颗粒。在 ChimeraX 中检查所有输出体积，再决定使用哪个。

分辨率到瓶颈了怎么办？

依次尝试：重新提取无裁剪颗粒 → Non-Uniform Refinement → Global CTF Refine → Non-Uniform → Local CTF Refine → Non-Uniform。每步检查 FSC 曲线变化。

对称性应该什么时候设置？

Ab-Initio 阶段如果不确定就用 C1。精修阶段再应用已知对称性。使用错误对称性会破坏重建，务必确认。

我应该用 Blob Picker 还是 Template Picker？

推荐流程：Blob/手动挑选（粗选）→ 2D 分类（生成模板）→ Template Picker（精细挑选）。有 GPU 资源可尝试 Topaz 深度学习挑选。

如何判断某个 2D 类别是否"好"？

好类别：清晰的二级结构细节、锐利边缘、高信噪比、颗粒数多。坏类别：模糊不清、冰/碳膜伪影、边缘效应、仅含 1–2 个颗粒。

附录 C：案例研究 — TRPV1 (EMPIAR-10059)

案例

DkTx-bound TRPV1

数据集：1,200 张已进行漂移校正的显微照片。

样品：大鼠 TRPV1 同源四聚体（~309 kDa），嵌入纳米盘。

对称性：C4（同源四聚体），但 DkTx 毒素以二聚体形式结合。

参数

采集参数

像素尺寸：1.2156 Å | 电压：300 kV

球差：2.0 mm | 总剂量：41 e⁻/Å²

Blob 挑选：100–130 Å 直径 → ~110 万初始颗粒

TRPV1 处理流程

Import Micrographs (跳过 Patch Motion，数据已校正) └─► Patch CTF Estimation └─► Manually Curate Exposures (CTF fit ≤ 6 Å，剔除 4 张 → 1,196 张) └─► Blob Picker (100–130 Å) → Inspect Picks → Extract (256→128) └─► 2D Classification → Ab-Initio → Heterogeneous Refinement └─► Template Picker → Extract → 2D Classification └─► Ab-Initio → Heterogeneous Refinement └─► Re-extract (256 px, 无裁剪) └─► Non-Uniform Refinement (C4 对称) ├─► Local Resolution → Sharpening └─► Mask (CTD) → Local Refinement → Sharpening
学习要点：此案例展示了如何处理对称性冲突（C4 全复合体 vs C2 毒素结合）、局部精修改善柔性结构域（CTD），以及 Particle Subtraction 隔离目标区域信号。
